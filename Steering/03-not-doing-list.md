# Not-Doing List

Explicit scope exclusions. This list exists to stop scope creep from both the designer and any AI agent working on the project. If a suggestion conflicts with a line below, it needs a deliberate decision-log entry to override it — it should never happen by default.

- **No 3D open-world traversal or real-time shooting/melee.** No Division-style third-person combat. Combat and raiding are resolved as decisions with odds (the venture pattern), not simulated in real time.
- **No fantasy, magic, or non-human races.** Fictional Western European setting, contemporary real-world technology only.
- **No per-faction branching focus trees (HOI4-style national focus trees).** Faction and leader identity comes from the trait engine (behaviour- and policy-derived), not from a menu of authored branches. *Amended 2026-09-25 (see decision log):* National Ambitions are allowed. Each faction gets its own ambitions, but they are drawn from **one pool written once in data**: each is available only when a faction's state qualifies (traits, government, tech, situation), so a raider gang and a merchant enclave see different lists because they have played differently. Government reforms are a small set of decisions unlocked the same way. Still excluded: separate authored trees per faction, and any fixed branching path a player can solve in advance.
- **No simulation of rival/regional cities.** The regional map is a node graph — settlements, nomad territories, the remnant state — each represented by a handful of stats (strength, wealth, traits, disposition). Only the player's own city has district-level simulation.
- **No block-by-block city simulation (Infection Free Zone-style).** The city map is district-based: 25–40 irregular districts, each with a small stat block (owner/influence shares, ruin level, population, grievance, resources, building slots). Control is a spectrum (unexplored → contested → claimed → secured → developed), not per-tile ownership.
- **No 3D character portraits in v1.** Living characters use 2D layered portraits (CK2-style); dead characters archive to flat 2D. A 3D portrait pipeline is a possible future stretch goal only if the playbox proves the core loop is fun — it is not committed scope.
- **No LLM-driven runtime AI.** Faction AI is rule-based: a weighted-scoring system (Paradox `ai_will_do`/`ai_chance`-style) over a small set of standing goals and available actions, using trait and relationship modifiers plus randomness. Predictable, debuggable, and legible to players.
- **No EU4-scale trade node network.** Trade is a handful of goods produced/consumed per district, not a continent-spanning node graph.
- **Regional map is not built in the playbox.** The playbox proves the city loop, the trait engine, and venture odds on the city map alone. The regional layer (and off-map crisis director) is added at the vertical slice stage, as an abstraction — not before.
